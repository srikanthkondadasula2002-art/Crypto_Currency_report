# CryptoCoin Analysis

## Project Overview

CryptoCoin Analysis is a Python-based data analytics project that collects cryptocurrency market data from CoinMarketCap, processes the data, performs exploratory analysis, and generates visualizations.

## Objective

The objective of this project is to analyze cryptocurrency market indicators such as:

- Cryptocurrency price
- 1-hour price change
- Market capitalization
- 24-hour trading volume
- Circulating supply

## Technologies Used

- Python
- Jupyter Notebook
- Pandas
- NumPy
- Requests
- BeautifulSoup
- Matplotlib
- Microsoft Excel

## Data Collection

The project uses Python web-scraping techniques with Requests and BeautifulSoup to collect cryptocurrency information from CoinMarketCap.

## Data Processing

Pandas is used to:

1. Create the DataFrame
2. Clean the collected data
3. Convert market values into numerical formats
4. Handle the extracted cryptocurrency information
5. Prepare the dataset for analysis

## Exploratory Data Analysis

The project analyzes:

- Cryptocurrency prices
- Market capitalization
- 1-hour price changes
- 24-hour trading volume
- Top cryptocurrencies by market capitalization
- Top cryptocurrencies by trading volume
- Relationships between numerical variables

## Visualizations

The project contains visualizations for:

- Cryptocurrency price comparison
- Market capitalization comparison
- 1-hour price changes
- 24-hour trading volume
- Top 5 cryptocurrencies by market capitalization
- Top 5 cryptocurrencies by trading volume
- Correlation analysis

## Output

The processed data is exported to Excel.

Output files:

- `crypto_analysis_output.xlsx`
- `crypto_analysis_final.xlsx`
